# ЗеркалоСвет — лендинг

Одностраничный сайт для мастерской по изготовлению и монтажу зеркал с LED-подсветкой в Ижевске.

## 🌐 Сайт

После публикации на GitHub Pages доступен по адресу:
`https://ваш-логин.github.io/название-репозитория/`

## 🛠️ Технологии

- HTML5
- CSS3 (адаптивная вёрстка)
- JavaScript (форма заявки)

## 📋 Что на сайте

- Услуги: изготовление зеркал с подсветкой, монтаж, крупные форматы, шкафы-купе
- Цены и этапы работы
- Форма заявки
- Контакты

## 📞 Контакты

- Телефон: 8 963 544-34-44
- Ижевск и пригород

## 🚀 Как обновить сайт

1. Загрузите новый `index.html` в репозиторий.
2. GitHub Pages обновит сайт автоматически в течение 1–2 минут.
